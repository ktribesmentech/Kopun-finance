Kopun Finance Manager v3 — Automated Finance System

This version automates the main day-to-day workflow of a small finance company: customer registration, application assessment, approvals, loan creation, due dates, repayment schedules, arrears, penalties, repayments, receipts, expenses, cashbook, statements, profitability, portfolio aging, alerts, staff roles, documents, audit trail and backups.

Automatic Workflow

Customer → Application → Affordability/Risk Check → Approval → Loan → Repayment Schedule → Collections → Arrears/Penalties → Statement → Reports → Audit.

Important Production Note

This is an offline single-file HTML application. It is useful for one-device operation and prototyping. A larger or regulated finance company should use a secured server/database, tested encrypted backups, formal access control, disaster recovery, and legal/compliance review before production deployment.
